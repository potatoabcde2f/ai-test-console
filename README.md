# AI Test Console

AI 测试控制台 - 用于测试不同 AI 模型的对话和生图能力。

## 功能

- 🤖 多模型对话测试
- 🎨 图像生成测试
- 📝 提示词管理
- 📊 对话结果存储与评测
- 🔍 模型对比

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 部署

本项目已配置 Vercel 部署。推送至 GitHub 后，在 Vercel 导入项目即可自动部署。

## 技术栈

- React + TypeScript
- Vite
- CSS 原生样式
